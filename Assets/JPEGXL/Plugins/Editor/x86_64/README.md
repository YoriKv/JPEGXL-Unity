libjxl v0.12.0 official Windows x64 dynamic build (https://github.com/libjxl/libjxl/releases/tag/v0.12.0, jxl-x64-windows.zip).
Editor-only native plugins used by the JPEG XL ScriptedImporter. Not shipped in players.
jxl.dll statically includes Highway (Apache-2.0) and skcms; brotli DLLs are MIT; libjxl is BSD-3-Clause. See LICENSE.*.txt.
Replacing a DLL requires an editor restart (native libraries cannot be unloaded).
